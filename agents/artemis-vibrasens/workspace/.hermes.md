# Espace de travail d'Artémis Vibrasens

- `client/` : le dossier du client (offre, vrais clients, cible validée, retours, `contexte.md`), tenu par l'orchestrateur (skill `cadrage-client`).
- `campagnes/<campagne>/` : une campagne par dossier (brief, vivier, vagues, lectures, qualification, `leads.xlsx`, `bilan.md`).
- `connecteurs/` : les connecteurs que le collecteur écrit lui-même, leur `index.md`, les fiches des sources par pays et `linkedin_seen.json`.
- Outils : `/opt/leadgen/venv/bin/python /opt/data/leadgen/outils/<outil>.py`. Catalogue des sources : `/opt/data/leadgen/docs/sources/catalogue.md`.
